# תאילנד שלי — אפליקציית תכנון טיול

אפליקציית ווב בעברית (RTL) לתכנון והחלטות לטיול בתאילנד. מותאמת ל־iPhone (~390px), בלי שלב בנייה.

## איך לפתוח

**אפשרות 1 — קובץ מקומי**  
פתחו את `index.html` בדפדפן (לחיצה כפולה / Open with).

**אפשרות 2 — שרת סטטי (מומלץ)**  
```bash
cd thailand-trip-app
python3 -m http.server 8080
```
ואז היכנסו ל־`http://localhost:8080` (או מכתובת המכשיר ברשת המקומית).

ב־Chrome DevTools: Toggle device toolbar → iPhone width.

## קבצים

| קובץ | תפקיד |
|------|--------|
| `index.html` | מעטפת UI, טאבים, מבנה מסכים |
| `styles.css` | עיצוב טרופי, mobile-first, RTL |
| `data.js` | אזורים, מסלולים מוכנים, אפליקציות, תוכן מדריך |
| `app.js` | אינטראקטיביות + `localStorage` |

## פיצ'רים

1. **Trip DNA** — חידון רב־שלבי → פרופיל + המלצות אזורים  
2. **גלה** — כרטיסי אזורים עם סינון לפי תחומי עניין  
3. **החלטות** — חופים / מסיבות / מסלול / גשם / תחבורה  
4. **מסלול** — בונה יום־אחר־יום, מסלולים מוכנים, ייצוא  
5. **תקציב** — סליידרים, THB + ILS, באפר  
6. **אפליקציות** — Grab, Bolt, Klook, Agoda, 12Go, LINE וכו׳  
7. **מדריך** — ויזה, SIM, בטיחות, ציוד (צ׳קליסט), חירום  
8. **בית** — דשבורד שמור מקומית  

נתונים נשמרים תחת המפתח `thailand-trip-app-v1` ב־localStorage.

## הערות

- שער ברירת מחדל: 1 THB ≈ 0.11 ILS (ניתן לעריכה במחשבון).  
- מידע ויזה הוא סקירה בלבד — יש לאמת מול מקורות רשמיים.  
- קישורים לאפליקציות הם deep links / אתרים אמיתיים, בלי API מזויף.
